# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built using HTML, CSS, and JavaScript. The game allows users to play against the computer, with each round determining a winner based on the classic Rock Paper Scissors rules.

### Features
- **Player vs Computer:** Play against a computer opponent that randomly selects rock, paper, or scissors.
- **Interactive Gameplay:** Select rock, paper, or scissors to play each round.
- **Random Computer Choices:** Computer generates a random choice for every round.
- **Winner Detection:** Automatically determines whether the user wins, loses, or draws.
- **Live Scoreboard:** Tracks and updates both the user's and computer's scores.
- **Dynamic Messages:** Displays game results and explains which choice beats the other.
- **Visual Feedback:** Changes message background colors to indicate wins, losses, and draws.

### Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation, Event Listeners, and Math.random())
